Monovu.vi

 

- Created by Minseong Lee (FSU physics graduate, currently at LANL Pulsed Field Facility). Please contact the distributor (Eun Sang Choi, echoi@magnet.fsu.edu) for suggestions and questions.

 

 

Notes:

Short keys for editing the sequence: Copy, Cut, Paste and Undo with Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+Z short keys for Mac. For windows, use Shift key instead Ctrl.

 

Subsequence: nestable subsequences can be used using Macro function

 

Error checking: Sequence errors (typos of the controls, instrument addresses) can be checked while editing the sequence or before executing the whole sequence.

 

(1) Functions

 

a.       Instrument control

·         Lake Shore temperature controllers (model 340, 336, 37X)

·         Lock-in amplifiers (Stanford Research, Signal Recovery)

·         Keithely sources (6221, 6517 (commands are compatible with other models in SCPI mode))

·         AH capacitance bridge

·         Motion control (through VI server)

 

b.      Field control (through VI server)

·         Any magnets using PS Control.vi for controlling the magnet

 

c.       Data acquisition program control (through VI server)

·         NML Data Acquisition (old and new version) vi.

·         Controllable parameters: Start, Stop, Trigger mode, Trigger value

 

d.      Writing commands to VISA instruments

 

e.       Time management

·         Wait until temperature or field to meet certain conditions (larger, smaller or withing 1 %)

·         Wait until a variable of a VI to meet certain conditions ((larger, smaller or withing 1 %)

·         Wait for a certain time.

 

f.        VI control

·            Run, abort, change parameters of the VI in the memory and over the internet. When used over the internet, VI server should be correctly set for the host computer.

 

g.      Keeping logs

·         Executed commands are recorded in a file named MonoVuLog Year-Month-Date.txt in the data file folder.

                       

 

(2) Sequence programming/execution. 

           

               a. Editing sequence

·         Insert commands: double-clicking the menus on the right panel

·         Copy, Cut, Paste and Undo with Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+Z short keys for Mac. For windows, use Shift key instead Ctrl key.

·         Modifying commands for upcoming (unexecuted) lines can be done any time.

·         Sequence file is text based and can be edited using any text editor program.

·         Sequence file can be saved for future use (some templates are available in the "sequence templates" folder)

 

               * Changing the number of lines (by adding or deleting) before the currently running command line should be used with caution.

                       

               b. Running sequence

·         Run, Pause, Stop, Skip (abort current command line and skip to the next) functions are available.

·         Sequence can be started from any line highlighted by the mouse cursor.

·         Sequence status shows the running status

·         Current line indicates the command line currently running

 

 

(3) Instrumentation overview

 

a.       Temperature control

·         The heater output and the excitation current can be controlled.

 

 

b.      Field control

·            For the original SCM1 and SCM2 magnet power supplies and  the resistive magnets: field stability condition is met when the field is close to the set field (0.001 T for superconducting magnets and 0.002 T for resistive magnets) of the set field AND the PS control.vi confirms that the field is stable.

·            For the other magnets : field stable condition is met when the target field is close to the set field.

 

c.       Stepper motor control

·            An independent stepper motor control VI (for example, stepper mover.vi or BLM_ManualControl.vi) should be running.

·            Use VI reference function to control the external stepper motor control VI.

·            "Wait for VI value" function can be used to wait until rotation is completed. Or simply use the "wait for" function.
